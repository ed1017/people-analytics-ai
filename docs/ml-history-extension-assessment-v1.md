**Do not run another RF/boosting experiment on the current evidence.** No newly
qualified historical source or predictor has been identified. Additional generated
years would test another assumed world, not recover older company observations.
The earlier RF/boosting rejections remain final for their tested scope. This
assessment adds no data, model, schema, production behavior or input boundary.

dataset author retained it. Without that evidence, improving real-world
reliability is outside what this synthetic project can demonstrate. This is a
stopping decision, not a proposal for another sequence of seed searches.

## Conditional evaluation contract, not an active experiment

There is **no new preregistered model run** because no qualified new input or
untouched source assessment is available. The following requirements bound any
future proposal; they are not claims that unavailable fields or untested stresses
have passed. Source availability and authorization must be resolved before a
concrete protocol can pin dates, features, sample sizes and hashes.

1. Start with one target: company-wide monthly voluntary-exit counts and their
   three-month sum. Compare a newly qualified reference window with one older
   contiguous comparable window. Preserve fixed native baseline lookbacks.
   If source qualification yields a leading signal, allow only that one signal
   plus its observed denominator/availability metadata. Never manufacture earlier
   feature values, zero-fill unknowns, bridge an instrument break or use future
   exposure. No ratings/promotion arm is reopened by default.
2. Before examining fresh assessment labels, freeze source hashes, as-known
   releases, exact feature/window candidates, training/development/end dates,
   hyperparameters, exclusions, missingness fallback, metrics and gates. Fit
   scalers/imputers on training only. Labels and completion must have been known
   at each historical fit; hiring/promotion maturity needs purging where relevant.
   Use matched chronological origins and embargo overlapping three-month targets
   across development/test. All previous tests are development knowledge now.
   If genuine later untouched releases are unavailable, stop.
3. Include recent-three, seasonal-naive-12, SES and nonnegative linear trend,
   plus regularized linear/calendar-seasonal regression receiving **every new
   covariate and the same training rows** as RF/GB. Pin the simple model's
   development selection; never choose the best baseline retrospectively per
   target cell. Report every fixed baseline on common support. Keep the existing
   5% aggregate improvement and 10% worst-cell limits at least as strict, now
   including seasonal/linear count comparators and monthly/quarter-total errors;
   preserve applicable coverage, bias and calibration guards. If sample support
   cannot evaluate those gates, mark unsupported rather than relax them.
4. Separate the history-only and signal-only additions in a predeclared small
   factorial: current/older history × absent/present one qualified signal. Show
   calendar-length learning curves at common origins, holding independent-source
   volume fixed; separately vary source-history volume at fixed length if truly
   independent histories exist. Repeated months, overlapping cohorts, scenarios
   and generated seeds are not independent real companies. Pair errors and
   cluster uncertainty by independent history; one source cannot establish
   transport robustness. Additional arbitrary fields are outside this test.
5. If a new **synthetic-only** research study is separately justified, preregister
   independently specified mechanisms before results, not merely new seeds or
   parameter tweaks to the current planted relationship. Cover no/weak/leading
   signal, varying signal persistence and delay, seasonality/level shifts,
   different shock timings and count scales, and incomplete releases. Use one
   development mechanism set and withheld mechanisms and histories; do not expose
   mechanism IDs, latent drivers or future labels as features. Have a separate
   reviewer specify/check withheld mechanisms. Freeze a finite run budget and
   report all outcomes. This tests synthetic transport only and cannot substitute
   for qualified observed history or demonstrate real-world efficacy.
6. Require incremental gain over equally informed simple models on the fresh
   assessment and preserve all worst-cell/support gates. Failure closes the
   candidate; do not tune on that test or search for favorable mechanism subsets.
   No calibrated forecast interval is claimed without a separately frozen,
   adequate temporal calibration and assessment design. Current intervals remain
   null; uncertainty in a paired error comparison is not forecast uncertainty.
