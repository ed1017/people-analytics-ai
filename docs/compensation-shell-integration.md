# Compensation shell integration

This integrates the unchanged aggregate-cost commit `6acb70ef261d133068f60826fbe6252e4425a219` (PR117) and public-reference commit `d14bd86cfe790801208598933ec3d5adbe1a97f7` (PR119) onto the compact Home/goal-chat branch (PR120). It mounts `CompensationPage` at the existing navigation destination and updates its page help, description, unavailable AI briefing and evidence-scope copy.

The public reference and internal cost source keep separate populations, periods, units and limitations. Reference selection is explicit; a goal mentioning an occupation does not select or validate a match. The shared workforce filters do not narrow either source. Internal salary analysis, salary recommendations and a Compensation AI briefing remain unavailable. The existing chat gate, disabled composer, empty prompt set and export boundary are retained. Navigation preserves the selected goal and its chat draft.

No database, auth, permission, Finance source, model-input or persistence changes are introduced by the shell integration. The aggregate endpoint retains the worker-reviewed allowlist from the existing Finance view, exact row-count guard, no-store response and sanitized errors. Its actual GET is executed with an isolated client stub in the unit suite; this integration does not repeat live database reads. The worker's source verification and limitations remain documented in the two source handoffs.

Validation: 899 unit tests, full lint, TypeScript and production build passed. There are 131 browser assertions: 51 production-shell checks at desktop, mobile and 200% reflow; 22 aggregate-cost component checks; and 58 public-reference component checks. The shell checks cover selected goal/country preservation, independent aggregate scope, no automatic occupation matching, unavailable AI controls, pending navigation cancellation, retry, return to Home, keyboard-scrolling tables, source limits and absence of model requests. API fixtures are synthetic and intercepted. Hosted preview and production acceptance remain separate release checks.
