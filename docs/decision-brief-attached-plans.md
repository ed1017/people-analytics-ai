The broad architecture roadmap is directional; later Home conversation-first decisions and bounded application contracts supersede the old migration sequence.

| Agreed requirement | Evidence and disposition |
| --- | --- |
| Understand workforce, then review a concrete goal and options | Home discovery, exact-goal preparation, scope gates, explicit Save/Calculate and capacity results are implemented. PR128 includes local follow-on measures; hosted release remains separate. |

| Preserve an attached decision with editable notes and explicit review | **Independent unfinished handoff selected:** Home attachments were absent from Decision Brief in both baselines. The Brief only read workforce, scenario and development records. A retention plan attached with no compatible destination fields was effectively invisible in the decision record. |
| Compare additional-capacity alternatives and feasibility | Existing bounded deterministic search, adoption review, unchanged calculator and linked-field application are implemented; this slice does not add optimization or retention modeling. |
| Historical evidence and assumptions remain inspectable | Existing immutable attachment records already contain the needed snapshots. This slice makes them visible in the Brief without changing storage or recalculating new scenarios. |
| Predictive turnover/hiring/satisfaction outputs | Local domain qualification is implemented; operational evaluation still requires verified completeness/observation histories and qualified cohort/wave extracts. Fixture results cannot supply them. |
| Assess achieved outcomes | The existing Assess & Evaluate destination remains explicitly future work. An outcome scorecard would require a separately defined observed-outcome contract and comparable observations; it is not smuggled into this handoff fix. |
| Release and real-service acceptance | No denied release/read retries. GitHub requirement evidence and exact-head hosted acceptance remain separate from independent local implementation. |

The new read-only Brief section uses `readBundleWorkspace`, including its existing deterministic result validation. It displays latest attached proposals, saved goal, cash and employee time separately, finish date, reviewed success measure and baseline provenance, activity owners/prerequisites, assumptions and unresolved inputs. Previous attached versions remain collapsed but inspectable. A different working draft is not substituted for an attachment. Changed goal wording is marked historical, and current evidence is deliberately not claimed revalidated by this page.

Absent attachments offer a direct Home review action. Malformed or cross-goal records are withheld with a recovery message and preserved untouched. No brief owner, notes, approvals, attachment, linked field or model input is written by viewing this section. Attachment remains a proposal, not organizational approval or measured benefit. No new page/panel in Home, source, schema, database, security/access or forecasting capability is introduced.
