# Goal-bound Action Plan panel

The selected plan remains above the conversation. One keyboard-accessible control collapses its title, description, summary, assumptions, evidence and attachment review together; the goal, tabs and compact selected-plan header remain available. Collapse state and the latest explicitly applied/attached option are browser-local and goal-bound. Merely previewing another tab does not replace the latest applied selection restored on a goal switch or reload.

The actions are Attach Action Plan, Apply changes and Compare Action Plans. Attach is available with expanded content and keeps the existing current-calculation/confirmation flow. Apply is enabled only for a reviewed pending diff matching the selected goal, plan, revision and current chat text. Applying saves the working draft, invalidates its prior calculation, leaves attached history immutable, and reports success even while collapsed. A stale diff cannot revive after a goal switch away and back. Compare shows existing drafts below the panel, focuses the comparison, uses responsive columns, and makes no model call or regeneration. Different scopes/targets are explicitly not like-for-like outcomes.

Validation: 1,076 unit tests; 312 browser assertions (36 panel, 48 what-if, 117 unified attachment, 18 clarification, 36 composer, 57 compact layout); lint, TypeScript and production build. Pointer/Enter/Space, collapsed chat updates, goal switches, reload, prior attachments, late preparation rejection and responsive widths are covered using intercepted synthetic APIs.
