## Single-option navigation

The comparison now shows one mounted card panel at a time, with Previous/Next arrows and Option tabs only for available cards. Arrow keys, Home and End move tab selection and focus; inactive tabs leave the tab order and inactive panels leave the accessibility tree. One-option fixtures disable arrows. Selection follows the option ID when order changes, and a changed goal/calculation remounts the existing verified source context. Switching does not persist any data.
