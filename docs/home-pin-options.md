# Home problem → pin → options

Home can prepare a concise problem and up to three qualitative candidates in the existing chat response. Pin as goal explicitly saves the exact displayed problem and its prepared candidates locally; pinning makes no model or calculator request. Optional edits retain their full text. Editing the problem invalidates prepared candidates and offers Generate options for this goal against the new wording.

Candidate actions are explicitly not calculated. Each has five bullets: intended outcome, unknown cost, unknown timing, unknown staffing, and why to investigate it. Details retains canonical source scope, date, limitation and navigation. Sources support investigation, not action effectiveness. The model must not invent numeric assumptions, availability, retention effects or operational approval. Fewer candidates, or one essential inline question, is valid.

The output-only contract adds bounded problem/options/question fields. Both server and client validate proposals using the existing normalized Home packet. Unknown/unavailable sources, quantitative predictions, malformed fields and excessive candidates fail closed to the ordinary answer. Duplicate candidates are removed. The existing Home request allowlist, packet normalization, input envelope and calculator payload are unchanged. Candidate records are never added to model inputs.

Saved candidates bind version, exact goal ID/text, original evidence-selection goal and the exact normalized source snapshot. Goal/evidence changes invalidate them. Old prose and unsupported saved record versions remain intact and require explicit Generate options for this goal; no automatic migration or model request runs. Pending responses are guarded by request context and goal-transition epoch. Pinning preserves the latest queued composer draft. Inline adjustment preserves separate drafts, guards changed option context, and sends only on Update options/Continue.

Quantify an option is optional. Review numbers opens the existing explicit scope review (or resumes existing local work). Additional role capacity requires its current review/save/calculate sequence and unchanged calculator. Replacement-only/uncertain scope cannot enter that model. No candidate becomes a calculated result. Existing verified calculated cards move above chat without remounting the planner, preserving drafts and result focus. Existing direct controls, toggles, Details and local Compare/Adjust/Explore remain.
